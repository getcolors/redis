Redis Package Skill

A reproducible Green workflow for one Redis 7.2 server on one Vultr instance in its own VPC: one Docker Compose service with noeviction and an append-only file, a password generated on the host, published on loopback and the VPC address only, reached over an SSH tunnel — with RDB backup sets in Cloudflare R2 and a rehearsal verb that proves one of them restores.

Small on purpose, proven anyway. One machine, one service, a firewall opening 22 alone. What convergence proves is the round-trip, the configuration read back from the running server, the two refusals, the exact bind addresses, persistence across a restart, and a backup set with a completion marker.

Quick start

npx skills add getcolors/redis
cp .agents/skills/package-redis-green/green ./green
chmod +x green
./green build
./green create --dry-run

Build renders reproducible output and dry-run walks the workflow without provider side effects. Real creation and deletion require explicit authorization.

What it builds

Infrastructure

One Vultr VPC, one instance in it, a firewall group admitting 22 from vultr-ssh-sources, and in keygen mode the account SSH key named after the profile.

Redis

The pinned 7.2 image, maxmemory-policy noeviction, appendfsync everysec on a named volume, requirepass from a create-once host secret, published on 127.0.0.1 and the VPC address.

Backups

RDB sets streamed over the replication protocol, checked with redis-check-rdb, uploaded to R2 under <profile>/redis/<stamp>/, completed last after a read-back.

Operator path

An SSH tunnel through the generated ~/.ssh/config alias, a SET/GET with the generated password, NOAUTH without it, and the public address not answering on the port.

Recovery is rehearsed, not assumed

./green rehearse takes a fresh set, restores the newest completed one into a scratch container of the pinned image with the AOF off — a Redis 7 started with AOF on and no appendonlydir/ ignores dump.rdb and starts empty — reads the smoke key back from it, and only then writes .colors-recovery-verified beside the sets.

Honest RPO. A restart loses at most a second of acknowledged writes. Losing the host loses the writes since the newest completed set: the rehearsal proves the set restores, and copying it into a fresh host is the operator's deliberate step.

Credentials

Every credential is a COLORS_PAR_* environment variable in a gitignored .envrc.private: the Vultr key, the state pair (reaches no host), and the backup pair — the one pair that reaches the host, scoped to the backup bucket. The Redis password is generated on the host and read over SSH.
